**Question:** apply the atlas to the market — the most native
application yet, because the market is compound relations all the
way down (the user's theorization, 2026-10-07): value with zero
intrinsic content, existing entirely in exchange relations. Three
skies — the tape (executable territory), fundamentals (the "value"
literature), narrative (the stories) — mapped against each other
to find the walls and the cracks.

## Triadic fork

1. **Claim:** the wall thesis holds in the market — the
   fundamentals sky and the tape barely touch except through
   narrow bridges (flows, surprises, positioning); the cracks
   are places where the tape holds something no sky states.
2. **Polar opposite:** the skies interweave widely — fundamentals
   (or narrative) explain price densely, no walls; the
   interweave itself is the mapped finding.
3. **Null / controls:** (a) drafters BLIND per sky — the tape
   drafters never see the fundamental/narrative vocabularies and
   vice versa. (b) POSITIVE CONTROLS: documented pairs MUST
   resolve — e.g., the earnings-announcement literature's own
   documented price response (tape↔fundamentals), and a
   documented news-event price impact (tape↔narrative). Else
   method failure, reported plainly. (c) fabrication
   spot-checks; the user's grading packet is the final leg.

## Corpus (pilot scale)

- **Tape sky:** a FIXED universe over a FIXED window, selected
  by the coordinator (direction: a broad index + a handful of
  single names, 1–2 years of daily bars minimum; intraday only
  if cleanly obtainable). ONLY actually-obtainable data —
  BK2011 strictly: if a series is not obtainable through the
  available instruments (browser finance vertical, public
  APIs, public datasets), it is dropped and recorded, never
  synthesized or proxied silently. Provenance per series in
  manifest.json.
- **Fundamentals sky:** 1–2 documents on fundamental valuation /
  earnings response (coordinator selects; IDs verified live).
- **Narrative sky:** 1–2 documents on news/sentiment and prices
  (coordinator selects; IDs verified live).

## Protocol adaptation — the first quantitative sky

The tape cannot be blind-extracted like a paper. Its drafters
are quantitative subagents following PRE-REGISTERED procedures:

1. The coordinator writes the tape-extraction procedures BEFORE
   any data is seen: fixed definitions of the structural
   concepts to extract (regimes, volume–price relations,
   volatility structures, gap/overnight behaviors, drawdown
   structures). The procedures are the drafter brief.
2. Tape drafters run the procedures, extract the concepts with
   the same schema (label, kind, status, note), blind to the
   other skies' vocabularies. No peeking, no tuning the
   procedures after seeing the text skies.
3. Text skies: standard one-shot R4 blind drafters per
   Atlas-2..8.
4. Merge + adjudication per Atlas-2..8 rules (explicit alias
   map, over-merge worse than under-merge, contradictions
   surfaced never adjudicated, role-differences named per D3).
   Semantic candidate review from the start (Atlas-3/4 lesson).
5. Crack verification runs AGAINST THE TAPE (the executable
   ground truth) — same as Atlas-8's sieve verification.
6. Illustrate: money view (three galaxies, gold links) +
   static PNG. Grade + cost: grading packet (sampled triples
   + ALL adjudications); token accounting per phase.

## Discriminating metrics (pre-registered)

- Sky↔sky link counts + density in Atlas-2..8 units, per pair
  (tape↔fundamentals, tape↔narrative, fundamentals↔narrative).
- Crack candidates: count, per-crack epistemic label,
  verification verdict against the tape.
- Controls resolved / method-failure.
- False merges bar 0. Contradictions 0. Drops with routes tried.
- Cost per phase, extrapolation shown.

## Honest limits (pre-registered)

- First non-textual sky: the quantitative-drafter adaptation is
  itself under test; the run grades the adaptation too.
- Market data is noisy, adversarial, non-stationary — unlike
  the sieve, the tape is not a clean ground truth, only an
  executable one. Verification here means "holds in the fixed
  window," not "true of markets."
- No live trading, no positions, no advice: this is a mapping
  run. Nothing in it is investment advice and the report says
  so plainly.
